## 项目背景

公益捐助长期面临'资金去向不透明、受助方身份核验难、捐赠人缺乏信任感'的问题。据中国慈善联合会2024年报统计，中国公益慈善捐赠总额已突破2200亿元，年增长率稳定在8%以上；与此同时，中国互联网公益峰会白皮书2025指出，超过62%的捐赠者表示'不知道自己的钱最终用到了哪里'，仅约15%的公益组织具备资金流向数字化追踪能力。

TraceAid 尝试用区块链记账 + 零知识证明核验的思路，给出一个产品层面的解决方案：

- 捐款进入平台账户后，按 1:1 比例铸造链上记账凭证（TAC Token），作为'资金上链'的可追溯锚点
- 受助方上传资助凭证（如学籍证明、收支票据）时，通过零知识证明（ZK）流程核验真实性，核验通过后哈希上链，原始隐私材料不外泄
- 平台侧引入异常检测机制，对可疑的资金流向/签核行为进行标记与复核

## B 端管理后台

本仓库中的 `index.html` 是管理后台的核心实现，主要模块包括：

| 模块 | 说明 |
|------|------|
| 数据看板 | 项目数、待办事项、受益学生数、本月筹款等核心指标可视化 |
| 项目管理 | 公益项目的全生命周期管理与状态追踪 |
| 多签审批工作流 | 资金支出/凭证核验的多角色签核流程设计 |
| 凭证记录与 ZK 核验 | 受助凭证上传 → 分步核验动画 → 哈希上链结果展示的完整交互流程 |
| 异常检测面板 | 资金流向/签核行为异常的标记与展开复核界面 |
| 反馈中心 | 捐赠人/受助方反馈的归集与处理 |
| 审批规则设置 | 多签阈值、核验规则等平台参数配置 |

**技术实现**：单文件 HTML + 原生 CSS/JavaScript，无框架依赖，包含约 2900 行代码，自行设计了完整的设计系统（色彩变量、图标体系、卡片/标签/弹窗等组件库）与页面状态管理逻辑（Tab 切换、分步表单、异常面板展开收起等）。

## 技术局限性（重要说明）

为避免误解，这里明确说明技术边界：

**本项目当前是前端产品原型（Demo），并非生产级系统。管理后台中的以下功能均为前端模拟交互效果，用于演示完整的产品流程和用户体验：**

- **链上铸造（TAC Token）**：铸造动画和数据展示为前端模拟，未连接真实区块链网络或智能合约
- **零知识证明（ZK）核验**：核验分步动画为前端交互模拟，未接入实际的 ZK 证明生成或验证算法库
- **AI 异常检测**：异常标记与评分逻辑基于前端预设规则和模拟数据，未接入机器学习模型
- **链上交易哈希**：展示的哈希值为模拟数据，未写入真实区块链

我负责的工作重点是**产品界面设计与前端交互实现**：把'资金上链记账''ZK 隐私核验''AI 异常检测'这类复杂技术概念，转化为普通管理员能看懂、能操作的清晰交互流程（例如 ZK 核验的分步进度动画、异常面板的展开式复核设计）。

## 竞品对比分析

TraceAid 定位于'区块链公益透明化平台'，以下对比基于各平台公开资料整理：

| 维度 | Gitcoin | Giveth | 腾讯公益 | 蚂蚁链公益 | TraceAid |
|------|---------|--------|---------|-----------|----------|
| 透明化程度 | 较高（链上公开） | 较高（链上公开） | 一般（传统模式） | 中等（部分上链） | 高（前端设计目标） |
| 隐私保护 | 有限 | 中等 | 有限 | 中等 | 高（ZK 方案设计） |
| 国内可用性 | 受限 | 受限 | 完全可用 | 完全可用 | 完全可用 |
| 中小机构友好 | 中等 | 中等 | 有限 | 门槛较高 | 高（轻量 SaaS） |
| 产品完整度 | B 端为主 | B 端为主 | 全平台 | B 端为主 | B+C 双端原型 |
| 本地化程度 | 英文为主 | 英文为主 | 中文完整 | 中文完整 | 中文完整 |

> 说明：TraceAid 的评估基于产品界面与流程设计目标，目前为前端原型阶段，尚未上线实际区块链网络。以上评分仅反映产品设计层面的差异化定位，不代表与成熟平台的功能对比。

### Gitcoin
全球最大的开源软件捐赠平台，基于以太坊。核心优势在于二次方融资（Quadratic Funding）机制和庞大的开发者社区。定位于开源项目资助，与传统公益场景不同，且国内访问存在网络限制。

### Giveth
基于以太坊的去中心化慈善平台，支持捐赠追踪。主要服务于加密货币社区，国内缺乏本地化运营与人民币支付通道。

### 腾讯公益
国内市场占有率最高的公益平台，依托微信生态和庞大用户基础。商业模式成熟、用户触达能力强，但技术架构仍以传统捐赠流程为主，未系统引入区块链实现全链路透明化。

### 蚂蚁链公益
蚂蚁集团旗下区块链公益解决方案，技术实力雄厚，已在多个项目中落地。但主要面向大型公益机构和企业客户，中小组织接入门槛较高，定制灵活性有限。

### TraceAid 定位与差异
- **双端完整产品**：B 端管理后台 + C 端用户平台，覆盖公益全流程的前端交互设计
- **ZK 隐私核验流程化**：以可交互的前端流程展示零知识证明核验概念
- **轻量化定位**：面向中小机构的 SaaS 方案，无需自建技术团队
- **中文原生体验**：完整适配国内公益行业场景与用户习惯
